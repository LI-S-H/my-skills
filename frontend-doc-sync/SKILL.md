# 前端契约同步

## 工作流程

1. 阅读 `references/doc-sync-checklist.md`。
2. 找出所有变化的字段、状态、动作、校验规则、响应结构和派生展示值。
3. 先更新最权威、最小范围的契约：schema/API 文档、类型定义、Mock 数据或页面文档。
4. 同步更新 API 适配层和测试。
5. 如果项目有契约检查命令，必须运行。

## 输出要求

说明哪些契约发生变化，以及哪些检查能证明页面展示和提交的数据都能被契约支持。
