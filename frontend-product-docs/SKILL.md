# 前端 PRD 生成

1. 阅读 `references/product-docs-guide.md`。
2. 定位目标项目根目录，并生成或更新 `<目标项目>/docs/product/PRD.md`。
3. 将已确认规则写入 PRD；不确定内容写入“待确认问题”。
4. 输出 PRD 路径、更新章节、待确认项，以及后续需要读取 PRD 的 skill。
