# 前端开发规范

## 工作流程

1. 阅读 `references/frontend-dev-must-read.md` 和 `references/frontend-dev-standards.md`。
2. 阅读项目本地前端规范、设计系统、API/schema 文档，以及最相似的已有页面。
3. 优先复用已有组件和页面模式。只有在能减少真实重复或符合项目架构时才新增抽象。
4. 从数据契约到页面模型再到 UI 实现，不允许用 Mock 数据掩盖字段缺失或业务状态不可能的问题。
5. 如果显示类问题重复出现，优先修成通用规则或通用组件；用户认可后再更新问题记录。

## 硬性规则

- 有现成组件时，不从视觉臆造开始。
- 不把无关字段混进一个列里，只为节省空间。
- 不给系统生成、审计、只读字段创建可编辑控件。
- 异步动作不能缺少加载态、防抖、请求序号或提交锁。
- 布局或交互有变化时，不能没有浏览器检查就交付。
